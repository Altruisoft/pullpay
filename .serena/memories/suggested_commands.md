Perintah utama project:
- `npm run dev` menjalankan dev server Vite/SvelteKit
- `npm run build` build produksi
- `npm run preview` preview hasil build
- `npm run check` sinkronisasi SvelteKit + type/check via `svelte-check`
- `npm run check:watch` mode watch untuk validasi
Di Windows, util umum tersedia via PowerShell/CMD, tetapi dalam harness ini gunakan tool internal untuk baca/cari/edit file, bukan shell util mentah.
