pullpay adalah landing page/web frontend untuk produk escrow trustless digital goods berbasis Stellar dan Soroban. Stack utama: SvelteKit 2, Svelte 5, TypeScript, Tailwind CSS v4, tailwind-variants, bits-ui, lucide-svelte, Lenis. Struktur utama: `src/routes/+page.svelte` merakit section landing; `src/lib/components/landing/*` berisi komponen section; `src/routes/layout.css` menyimpan design tokens CSS; `src/lib/tokens.ts` menyimpan token TS paralel; aset statis berada di `static/images`. Kondisi saat ini: masih ada komponen landing lama bertema gelap/ungu yang perlu diganti ke arah Swiss minimal oranye sesuai brief baru.
