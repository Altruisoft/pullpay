Konvensi project: komponen ditulis dengan Svelte 5 (`$props`, `$derived`, `onMount` bila perlu), TypeScript, dan utility class Tailwind langsung di markup. Komponen reusable ada di `src/lib/components/ui/*` dan layout helper di `src/lib/components/layout/*`. Design tokens hidup di dua tempat: CSS custom properties di `src/routes/layout.css` dan token TS di `src/lib/tokens.ts`; perubahan visual sebaiknya menjaga keduanya tetap selaras. Naming file memakai PascalCase untuk komponen Svelte, camelCase untuk ekspor data, dan copy landing disuplai dari `src/lib/components/landing/data.ts`. Hindari pola visual generik web3 (ungu, gradient berat, dashboard padat); ikuti brief Swiss minimal oranye.
